## The shape that breaks

An adopting repository usually has the application's own project at the root and the project
that drives it underneath:

```
<your repository>/
  {adoption.shape.application}
  {adoption.shape.driving}
```

That is the natural place to put it, and it is the arrangement that fails. Every default glob
the SDK applies reaches the **whole tree below the project file**, so the driving project gets
compiled *into* the application.

## Reading that

Nine errors, every one of them `CS0579`, every one naming a generated file, and not one of them
naming the folder that caused it. With `UseWPF` on, the project in the brackets can be a
`_wpftmp` project you never wrote — which reads like a WPF problem and sends you looking through
XAML.

It is not WPF and it is not the generated files. The driving project's own build wrote a set of
assembly attributes, the application's globs reached down and compiled them as well as its own,
and two copies of one attribute is what `CS0579` is.

<Aside type="caution" title="Why this arrives late, and about the wrong project">
The application builds cleanly until something has built the driving project — so it appears the
first time somebody runs the whole thing rather than when the folder was added, and the error
names the project that was fine.
</Aside>

## The one line that repairs it

In the **application's** project file, not the driving one:

```xml
{adoption.excludes}
```

<Captured step={3} />

`DefaultItemExcludes` and not a `Compile Remove`, because it is every glob and not only that
one: `Page`, `Resource` and `EmbeddedResource` reach down there too, and an application with
`UseWPF` on applies all of them.

<Aside title="This repository holds itself to that line">
`samples/Adopter` is an adoption kept inside this repository, with a driving project underneath
it for exactly this reason. The line above is read out of that project file when the capture is
taken, so it is the spelling this repository actually depends on rather than one written for a
page — take it out there and the sample is what fails.
</Aside>
